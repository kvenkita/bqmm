# Hall-Sheather bandwidth for quantile sparsity estimation

Hall-Sheather bandwidth for quantile sparsity estimation

## Usage

``` r
hall_sheather_bandwidth(n, tau, alpha = 0.05)
```

## Arguments

- n:

  Sample size.

- tau:

  Quantile level.

- alpha:

  Nominal level for the bandwidth (default 0.05).

## Value

A positive bandwidth.
